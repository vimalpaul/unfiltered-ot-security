# OT and ICS Glossary

This glossary gives concise working definitions. A term may have a more specific meaning in a particular standard, vendor product, or sector.

| Term | Working definition |
|---|---|
| OT | Programmable systems and devices that interact with or manage interaction with the physical environment. |
| ICS | Industrial control systems used to monitor or control industrial processes. |
| SCADA | Supervisory control and data acquisition systems used for geographically distributed monitoring and control. |
| DCS | Distributed control system used to control industrial processes through distributed controllers and operator interfaces. |
| PLC | Programmable logic controller used for industrial control tasks. |
| RTU | Remote terminal unit used for telemetry and remote monitoring or control. |
| HMI | Human-machine interface used by operators to monitor and interact with processes. |
| SIS | Safety instrumented system designed to achieve or maintain a safe process state. |
| IED | Intelligent electronic device used in protection, control, and automation, especially in power systems. |
| Historian | System that collects and stores time-series process and operational data. |
| Engineering workstation | Workstation used to configure, program, diagnose, or maintain control system assets. |
| Purdue model | Reference model that organizes industrial and enterprise functions into conceptual levels. |
| Zone | Group of assets with common security requirements and risk characteristics. |
| Conduit | Controlled communication path between zones. |
| Industrial DMZ | Boundary network used to broker and control exchanges between enterprise and industrial environments. |
| IIoT | Industrial Internet of Things: connected sensors, devices, platforms, and services used in industrial contexts. |
| OT SOC | Security operations capability tailored to industrial systems and process constraints. |
| FAT | Factory acceptance testing performed before equipment or systems are accepted from a supplier. |
| SAT | Site acceptance testing performed after installation at the operational site. |
| MOC | Management of change process for controlled changes to equipment, process, software, or procedures. |
| BPCS | Basic process control system responsible for normal process control. |
| F&G | Fire and gas detection and protection systems. |
| EWS | Engineering workstation. |
| P&ID | Piping and instrumentation diagram. |
| RPO | Recovery point objective: acceptable data loss measured in time. |
| RTO | Recovery time objective: target time to restore a service or capability. |

## Usage note

Use the terminology and definitions of the applicable standard or regulator when writing compliance or engineering documents. This glossary is explanatory and does not supersede normative definitions.
